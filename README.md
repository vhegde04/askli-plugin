# Askli

Askli turns product questions into AI-moderated customer interview studies and evidence-backed Decision Reviews. The same public plugin works in Cursor and other clients that support Agent Plugins.

The plugin combines an automatically discoverable customer-research skill with Askli's hosted MCP server. It can create and clarify studies, review plans, prepare participant options, report progress, and retrieve findings linked to interview evidence.

Askli preserves the customer's stated audience and constraints. It does not silently broaden an unsupported audience, collect payment details in chat, or present qualitative research as population-level certainty.

## Install in Cursor

Use Askli's verified one-click installer and manual setup instructions:

https://www.askli.chat/integrations/cursor

The plugin connects only to Askli's production Streamable HTTP endpoint:

```text
https://www.askli.chat/api/mcp
```

Sign-in uses Askli OAuth. The plugin contains no credentials or customer data.
