# Askli

Askli turns product questions into AI-moderated customer interview studies and evidence-backed Decision Reviews.

The plugin combines an automatically discoverable customer-research skill with Askli's hosted MCP server. It can create and clarify studies, review plans, prepare participant options, report progress, and retrieve findings linked to interview evidence.

Askli preserves the customer's stated audience and constraints. It does not silently broaden an unsupported audience, collect payment details in chat, or present qualitative research as population-level certainty.
